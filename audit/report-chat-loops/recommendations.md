# Report chat 20-loop test: recommendations outside the chat code

These came up during the 2026-11-03 test loops. Under the agreed scope, I left them unchanged, because they're outside the chat code.

| # | Loop | Area | What I saw | Recommendation |
|---|------|------|-----------|----------------|
| 1 | 3 | Data / AI Visibility Lite | Soteri Skin's AI Visibility Lite run tracks **"Position²"** as the client brand, with competitors cottonique and ducray. So the chat tells Soteri Skin it was "named in 0 of 60 answers" for prompts about marketing agencies. | Check the project's brand settings for that run. It looks like test data, or a run set up with the wrong brand. |
| 2 | 5 | Scoring / Agent Readiness | For Soteri Skin, the dashboard card and executive summary say Agent Readiness is **41/100**, while the report open on screen recomputes as round(50 ÷ 119 × 100) = **42**. By the documented method, the card is the *average of the audited scans*, so this may be correct: the gap comes from other scans. The chat now gives both and says which is which. | Confirm that the card is an average over several scans. If it is, consider labelling the card "average of N scans" so the gap is visible without the chat. If there is only one scan, it's a scoring mismatch (for the scoring session). |
| 3 | 7 | Explainer copy / SEO & GEO | The SEO & GEO "Page score" info-icon text (`calc`) says **"The overall score blends the two sides."** The scorer (seoGeoChecks.calculateScores) takes a weighted mean of the 8–9 areas and never blends the SEO and GEO side scores. In early tests the chat repeated this wrong claim. | Reword the explainer `calc` in client/src/components/explain/ to something like: "The page's checks are grouped into weighted areas; the overall score is the weighted average of the areas. The SEO and GEO scores are separate views of their own areas." The chat now overrides it with the exact method, but readers still see the wrong text in the info icon. |
| 4 | 8 | Explainer copy / Agent Readiness | The Agent Readiness info-icon text says "The score is the points earned **out of 100**". When on-page checks run, the denominator is 100 + on-page points available (119 for Soteri Skin). | Reword it as "the points earned as a share of the points available (100, plus any on-page checks that ran)". |
